# Standards & frameworks — pointer files only

**No standard text is stored in this repo.** ISO/IEC 27001, ISO/IEC 42001 and the AICPA
Trust Services Criteria (SOC 2) are copyrighted. Each pointer file below records the
official identifier, edition, publisher, where to obtain a licensed copy, and what
`warden` does with it (authored summaries + clause/control numbers only).

| Framework | File | Licence status | What warden stores |
|---|---|---|---|
| ISO/IEC 27001:2022 (+ Amd 1:2024) | iso-iec-27001.md | © ISO/IEC — paid licence | clause/control numbers + authored summaries |
| ISO/IEC 42001:2023 | iso-iec-42001.md | © ISO/IEC — paid licence | clause/control numbers + authored summaries |
| AICPA Trust Services Criteria (SOC 2) | aicpa-tsc-soc2.md | © AICPA — free download, no redistribution | criterion IDs + authored summaries |
| OWASP Top 10 for LLM Applications 2025 | owasp-llm-top10.md | CC BY-SA 4.0 | risk IDs/names + authored summaries + link |

Rule for contributors: if you need the wording of a clause, open your licensed copy.
Never paste it here, in `frameworks/`, in `analysis/` or in `skill/`.
